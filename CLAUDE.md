# CLAUDE.md

See [AGENTS.md](./AGENTS.md) for full project rules, design system guidelines, editorial style, and instructions on how to add or modify blogs.

### Key Rules
- Zero glassmorphism, zero unnecessary emojis, zero flashy animations.
- Minimalist, high-readability design (`Inter` + `JetBrains Mono`).
- Dynamic routing under `blogs.mgbuilds.in/` (index) and `blogs.mgbuilds.in/[slug]`.
- Always verify changes with `npm run lint` and `npm run build`.
